## Tried JekyllPad for my github.io page

Hi, there.  
I was keep looking for the way I could add web editor in my github pages so that I won't have to open the vscode for adding new post.

### And I found this JekyllPad([https://www.jekyllpad.com/](https://www.jekyllpad.com/))!

It works like the text editor of the blog.  
Of course it has a little bit of problem handling the images(I could not add the image and see the images of my previous postings), but for editing text, it is wonderful!

(Oh, and I found I can't change the colors of the text with buttons in the web editor.)

Let's see the code block.

```javascript
console.log('JekyllPad');
const a = 1;
```

It works and it also catch which language I used automatically.
